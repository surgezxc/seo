## Порядок публикации

2. Публиковать по одной в 3–4 дня, а не все сразу: двадцать новых адресов за
   день Яндекс индексирует медленнее и хуже.
3. После публикации каждой — ссылка с целевой страницы в блоке «Полезное».
4. Адреса статей — на латинице, без даты: slug — имя файла без даты, `2026-11-18-check-flat.md` → `/blog/check-flat/`. Транслит заголовка не выдумываем.

  налоговой;
