# Архив статей

Три статьи про запуск агентства недвижимости сняты с публикации 18 ноября 2026
решением исполнителя: они прямо учат читателя обойтись без платной услуги
(«запуск агентства под ключ», от 600 000 ₽) или уйти к франчайзеру. Для сайта,
который эти услуги продаёт, это минус, а не лид-магнит.

- `2026-11-18-agency-open.md` — пошаговая инструкция «как открыть агентство самому».
- `2026-11-18-agency-business-plan.md` — как самому посчитать бизнес-план.
- `2026-11-18-franchise-or-own.md` — сравнение франшизы и своего агентства.

Файлы не удалены: если заказчик захочет вести блог про запуск агентств как
отдельное направление с кейсами — переделаем в «как мы запускаем агентство».
