8. **В порядке:** `robots.txt` (закрыты только `/api/` и `/legal/`), `sitemap.xml`

9. **`sitemap.xml` статический:** `lastmod` у всех адресов — 30 октября, при том

10. **Цена консультации расходится в четырёх местах:** два на главной (ответ в

## 2. Блок 2. GEO-лид на каждой странице (приоритет 1)

Зачем: ответ Алисы и блок «Нейро» цитируют абзац, а не заголовок. Если в первых
предложениях нет города, названия компании и цены, цитировать нечего — Яндекс
возьмёт агрегатор.

Правило для всех страниц и статей:

1. Первый абзац — 4–6 предложений, прямым ответом, без «в современном мире».
2. В нём обязательно: кто делает работу, в каком городе, что входит, цена,
   чего не обещаем.
3. Абзац лежит в HTML сразу: не в аккордеоне, не во вкладке, не после клика.
4. Цифры только те, что уже есть на сайте. Никаких новых сумм и сроков.
5. Абзац не заменяет H1 и не дублирует его дословно.
6. Консультация платная: пишем «от 5 000 ₽», как на сайте. Слова «бесплатно»
   нет ни в тексте, ни в разметке.

ответами. Новые тексты не нужны — нужна разметка. Блок вставить целиком в

Требования:

## 8. Блок 8. Технические мелочи (приоритет 2)

1. **Open Graph на каждой странице свой.** Сейчас `og:title`, `og:description`,
   `og:url` — с главной на всех адресах. Сделать по аналогии с `title` и
   `canonical`.
2. **`sitemap.xml` генерировать при сборке**: `lastmod` — дата последней правки
   страницы, состав — все существующие адреса. Сейчас статика от 30 октября.
3. **`robots.txt` не менять.** `/legal/` закрыт, и это правильно.
4. **Метрику и мета-тег Вебмастера не трогать.** `113897560`,
   `25a9a7f3c60335b7`.
5. **`canonical`** — оставить самоссылающимся на каждом адресе, как сейчас.
6. **404-страница.** Сейчас `/proverka-obekta/` отдаёт 404-страницу весом под
   800 КБ. После создания страницы вопрос снимается, но если шаблон 404 тяжёлый —
   почистить: на несуществующие адреса поисковик ходит регулярно.
7. **Кэширование HTML.** `Cache-Control` на HTML сейчас не отдаётся. Для
   статической сборки достаточно короткого кэша с ревалидацией по `ETag`.

## 9. Блок 9. Приёмка: команды и что должно получиться

Проверять по публичным страницам, не по кабинету. Порядок — после каждой
выкладки.

```bash
# 1. Title и H1 по шести страницам
for u in "" yuristy/ sdelki/ analiz-kommercii/ prodazha-kommercii/ zapusk-agentstva/; do
  echo "== /$u"
  curl -s "https://gk-anvgarant.ru/$u" -o /tmp/p.html
  grep -o '<title>[^<]*' /tmp/p.html | head -1
  python3 - <<'PY'
import re
h = open('/tmp/p.html', encoding='utf-8').read()
m = re.search(r'<h1[^>]*>(.*?)</h1>', h, re.S)
h1 = re.sub(r'\s+', ' ', re.sub(r'<[^>]+>', ' ', m.group(1))).strip() if m else 'НЕТ'
print('H1:', h1)
h2 = re.findall(r'<h2[^>]*>(.*?)</h2>', h, re.S)
if h2:
    first = re.sub(r'\s+', ' ', re.sub(r'<[^>]+>', ' ', h2[0])).strip()
    print('первый H2:', first, '| ДУБЛЬ с H1' if first == h1 else '')
PY
done

# 2. Разметка: блоки JSON-LD парсятся, нужные типы на месте
curl -s https://gk-anvgarant.ru/sdelki/ -o /tmp/p.html
python3 - <<'PY'
import re, json
h = open('/tmp/p.html', encoding='utf-8').read()
blocks = re.findall(r'<script[^>]*type="application/ld\+json"[^>]*>(.*?)</script>', h, re.S)
bad = 0
for b in blocks:
    try:
        json.loads(b)
    except Exception:
        bad += 1
types = sorted({t.strip(' "') for t in re.findall(r'"@type":\s*(\[[^\]]*\]|"[A-Za-z]+")', h)})
print('блоков:', len(blocks), '| с ошибкой:', bad)
print('типы:', '; '.join(types))
PY

# 3. Новая страница живая
curl -s -o /dev/null -w 'proverka-obekta: %{http_code}\n' https://gk-anvgarant.ru/proverka-obekta/

# 4. Адреса в sitemap и даты lastmod
curl -s https://gk-anvgarant.ru/sitemap.xml | grep -o '<loc>[^<]*'
curl -s https://gk-anvgarant.ru/sitemap.xml | grep -o '<lastmod>[^<]*' | sort -u

# 5. og:url страницы услуги совпадает с её адресом
curl -s https://gk-anvgarant.ru/sdelki/ | grep -o 'og:url" content="[^"]*'
```

## 10. Чего не делать

- **Не менять URL** существующих страниц. Все адреса остаются как есть.
- **Не добавлять фото** людей и офиса — так решено.
- **Не добавлять кнопку «заказать звонок».** Конверсия — `tel:` и мессенджеры.
- **Не писать «бесплатная консультация»** и «гарантируем чистоту».
- **Не ставить сроки в днях** и цены, которых нет на странице.
- **Не трогать** основной текст, цены, реквизиты, часы, Метрику, мета-тег
  Вебмастера.
- **Не заводить** страницы «о компании ради текста» и блог без запроса.
- **Карточки в Яндекс Бизнесе — не ваша зона.** Их правит Владислав по своим
  доступам: там сейчас чужой телефон и дубль в Геленджике. Если увидите
  расхождение адреса или телефона между сайтом и карточкой — сообщите, не
  правьте.

## 11. Решения, которые уже приняты

Вопросов к вам здесь нет: спорные места закрыты на нашей стороне, чтобы вы не
гадали.

1. **Звонок бесплатный, консультация платная — от 5 000 ₽.** На страницах
   стоит ровно это: «Первый звонок — бесплатно. Разберём ситуацию и скажем,
   нужна ли проверка». Бесплатной консультации нет, и слова «бесплатная
   консультация» на сайте не должно быть нигде, включая карточку Карт.
2. **Цену на сайте не меняем.** Бейджи «от 5 000 ₽», «3%», «от 100 000 ₽» и
   «от 600 000 ₽» остаются как есть. `FAQPage` и `Service` повторяют их дословно.
3. **H1 главной не трогаем** — `Недвижимость без скрытых рисков`. Город уходит в
   title, этого достаточно.
4. **Тексты для `/yuristy/`, `/sdelki/` и `/zapusk-agentstva/` пришлём отдельно**
   (блок 6.1). Шаблон под них подготовьте заранее.
5. **URL не меняем**, статьи кладём в `/blog/<slug>/` — это финальное решение,
   не заготовка.
