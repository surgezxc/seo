3. Если позже добавите вопросы — дописать их в `mainEntity`.

## Задача 2: хлебные крошки на пяти страницах

На странице `/sdelki/` (для остальных — по образцу, меняя название и URL):

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "BreadcrumbList",
  "itemListElement": [
    {
      "@type": "ListItem",
      "position": 1,
      "name": "Главная",
      "item": "https://gk-anvgarant.ru/"
    },
    {
      "@type": "ListItem",
      "position": 2,
      "name": "Сопровождение сделки с недвижимостью",
      "item": "https://gk-anvgarant.ru/sdelki/"
    }
  ]
}
</script>
```

Названия для остальных страниц:

| URL | name в крошках |
|---|---|
| `/yuristy/` | Юрист по недвижимости |
| `/analiz-kommercii/` | Анализ коммерческой недвижимости |
| `/prodazha-kommercii/` | Продажа коммерческой недвижимости |
| `/zapusk-agentstva/` | Запуск агентства недвижимости |

На главной крошки не нужны.

## Проверка после выкладки

1. Яндекс.Вебмастер → «Инструменты» → «Валидатор разметки» — вставить URL,
   убедиться, что `FAQPage` и `BreadcrumbList` распознаны без ошибок.
2. Или валидатор Schema.org: `validator.schema.org`.
3. Написать в чат — сверю через `curl`, что блоки в HTML.

## Что это даёт и чего не даёт

**Даёт:** машиночитаемые вопросы и ответы. Яндекс и Google точнее понимают, что
на странице есть готовые ответы — это повышает шанс на расширенный сниппет и на
цитирование в ответах Алисы и Нейро (блок GEO в плане).

**Не даёт:** само по себе не поднимает позиции. Разметка — не рычаг
ранжирования, а способ оформить уже имеющийся контент. Ждать от неё скачка
нельзя.

**Важно:** и Яндекс, и Google показывают расширенные сниппеты не всем и не
всегда. Отсутствие сниппета после разметки — не ошибка.
