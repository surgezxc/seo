# ТЗ: заголовки и разметка

## Коротко

| Что | Где | Зачем |
|---|---|---|
| Title, H1, description | 5 страниц услуг | Региональный сигнал по коммерческим запросам |
| Разметка FAQPage | главная | Машиночитаемые ответы: сниппет и цитирование Алисой |
| Разметка BreadcrumbList | 5 страниц услуг | Путь в выдаче, понимание структуры |

## Чего не трогаем

- Адреса страниц. Менять URL нельзя — потеряются позиции.
- Основной текст, цены, телефон, почту, часы, реквизиты.
- Разметку `LegalService` и `RealEstateAgent`, `areaServed`.
- Метрику `113897560` и мета-тег Вебмастера `25a9a7f3c60335b7`.
- H1 главной (`Недвижимость без скрытых рисков`) — отдельное решение, ниже.
- Кнопку «заказать звонок» не добавлять.

# Часть 1. Заголовки

Ограничения: title до 70 символов, H1 до 70, description до 160. Города пишем
в именительном падеже, без «г.».

# Часть 2. Разметка

## 2.1. FAQ на главной

Одиннадцать вопросов и ответов уже есть на странице — новые тексты не нужны.
Вставить в `<body>` главной один блок, целиком:

  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "Сколько стоит первичная консультация?",
      "acceptedAnswer": {
        "@type": "Answer",

      "@type": "Question",
      "name": "Можно ли получить консультацию дистанционно?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "Да, мы консультируем по телефону и в мессенджерах — приезжать в офис для первого разговора не обязательно."
      }
    },
    {
      "@type": "Question",
      "name": "Какие документы нужны для проверки квартиры?",
      "acceptedAnswer": {
        "@type": "Answer",

## 2.2. Хлебные крошки на пяти страницах

Пример для `/sdelki/`:

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "BreadcrumbList",
  "itemListElement": [
    {
      "@type": "ListItem",
      "position": 1,
      "name": "Главная",
      "item": "https://gk-anvgarant.ru/"
    },
    {
      "@type": "ListItem",
      "position": 2,
      "name": "Сопровождение сделки с недвижимостью",
      "item": "https://gk-anvgarant.ru/sdelki/"
    }
  ]
}
</script>
```

Для остальных страниц меняются `name` и `item` во втором пункте:

| URL | name |
|---|---|
| `/yuristy/` | Юрист по недвижимости |
| `/analiz-kommercii/` | Анализ коммерческой недвижимости |
| `/prodazha-kommercii/` | Продажа коммерческой недвижимости |
| `/zapusk-agentstva/` | Запуск агентства недвижимости |

На главной крошки не нужны.

# Отдельным решением: H1 главной

Сейчас: `Недвижимость без скрытых рисков` — слоган, города и услуги нет.

Предложение: H1 → `Недвижимость и право в Новороссийске и Геленджике`, слоган
оставить подзаголовком. Усилит главную по региону, но меняет лицо сайта —
нужно согласие. Без согласия оставляем как есть: пять страниц дают основной
эффект.
