Считать нечего, кроме `tel:` и мессенджеров.

## Четыре цели

| Название | Тип в Метрике | Условие |
|---|---|---|
| Звонок с сайта | Клик по номеру телефона | все ссылки `tel:` |
| Telegram | Переход в мессенджер | только Telegram (`t.me`) |
| WhatsApp | Переход в мессенджер | только WhatsApp (`api.whatsapp.com`) |
| MAX | Переход в мессенджер | только MAX (`max.ru`) |

Почему четыре, а не одна общая «обращение»: заказчику нужно видеть, какой канал
даёт контакты. Одна суммарная цифра это скрывает.

Создаём вручную, автоцели не включаем. Считают они то же самое — Метрика ловит
клик по ссылке в обоих случаях, код не нужен. Разница только в списке: ручная
цель видна сразу и даёт отдельную цифру по каналу, автоцель появляется после
первого клика одной общей строкой «Переходы в мессенджер». Если такая строка
всё же появится, удалять её не надо — переименовать в «Мессенджеры, все».

## Как настроить

1. Открыть https://metrika.yandex.ru/ под аккаунтом Владислава, выбрать счётчик
   **113897560** («АНВ Гарант»). Часовой пояс счётчика — Москва, он же рабочий.
2. **Цели** → **Добавить цель** → **Клик по номеру телефона** → название
   `Звонок с сайта` → **Добавить цель**. Условий по номеру не задавать: номер
   на сайте один.
3. **Добавить цель** → **Переход в мессенджер** → название `Telegram` → из
   списка оставить только Telegram → **Добавить цель**. Повторить для
   `WhatsApp` и `MAX`, каждый раз один мессенджер.
4. Доход цели (ценность) не заполнять. Сумма по клику неизвестна: консультация
   5 000 ₽, проверка объекта считается за объект. Придуманное число испортит
   отчёт, а не украсит.

## Как проверить, что считается

1. Открыть сайт в приватном окне — иначе визит может отсечь настройка
   «Не учитывать мои визиты».
2. Нажать телефон, Telegram, WhatsApp, MAX.
3. Через 5–15 минут: **Отчёты → Конверсии**, период «Сегодня». В строке каждой
   цели должна появиться хотя бы одна конверсия.
4. Точная проверка — **Вебвизор**: открыть последний визит, в нём видно клик и
   срабатывание цели.

Если данные не появились через 30 минут, смотреть не цель, а счётчик: грузится
ли `mc.yandex.ru/watch/113897560`, не отключён ли `trackLinks`.

## Чего цель не показывает

Это важно проговорить, чтобы отчёт не превратился в выдумку.

1. **Клик ≠ звонок.** На компьютере `tel:` часто ничего не открывает, но клик
   засчитан. По клику нельзя сказать, что человек дозвонился.
2. **Данные только с даты создания цели**, назад не считаются. Первую неделю
   нули — это нормально, а не поломка.
3. **Цель по мессенджеру** = человек открыл чат, а не написал. Переписку Метрика
   не видит.
4. **Реклама и боты** тоже кликают. Всплеск без визитов — повод смотреть
   источники, а не радоваться.
5. Заказчику писать «кликов по телефону — N», а не «звонков — N». Это разные
   числа, и второе мы не знаем.

## Раз в неделю

**Отчёты → Конверсии**, период «Неделя»: количество по каждой из четырёх целей.
Дальше — разрезы, если цифры не нулевые:

- по страницам входа — какая услуга собирает контакты;
- по источникам — поиск, карты, прямые заходы.

В недельный отчёт идёт одна строка: «телефон N, Telegram N, WhatsApp N, MAX N
кликов». Сумму не складывать в «обращения»: часть людей жмёт два канала подряд.

## Если MAX не считается

По справке Метрики MAX поддержан (`https://max.ru` в ссылках), поэтому скорее
всего всё заведётся. Если через сутки по MAX ноль, а по Telegram есть — нужен
код от разработчика заказчика, в репозиторий сайта не лезем. Цель типа
**Целевое событие** с идентификатором `MAX` и скрипт:

```js
document.addEventListener('click', function (e) {
  var a = e.target.closest('a[href*="max.ru"]');
  if (a && window.ym) ym(113897560, 'reachGoal', 'MAX');
});
```

Ставить в общий шаблон страниц, после кода счётчика. Проверить так же, в
приватном окне.
