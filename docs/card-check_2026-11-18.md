```bash
curl -s -A "Mozilla/5.0" https://yandex.ru/maps/org/anv_garant/164738630687/ \
  | grep -o '+7[ (]*9[0-9]\{2\}[ )-]*[0-9-]\{7,10\}' | sort -u
```

Должно быть `+7 (989) 030-13-33`. Пока выводит `+7 (900) 243-18-38` — не
готово.
