# Заголовки по базе запросов: одна страница — один запрос

Дата: 18 ноября 2026.

## Контекст

В ТЗ №3 оказалось два набора title/H1: таблица в блоке 1 и блоки «Мета» в
приложениях А–Е. На пяти страницах из шести они расходились, причём варианты
целились в разные запросы: «юрист по недвижимости» против «юрист по сделкам»,
«запуск агентства с нуля» против «запуск под ключ». Ни в одном наборе не было
привязки к базе из 78 запросов, а в тексте — ни одного упоминания Топвизора,
Wordstat или частотности.

Отдельно выяснилось, что фраза «проверка объекта» — наша, а не людей: в базе
стоят «проверка юридической чистоты квартиры» и «проверка документов на
квартиру». Новая денежная страница называлась словами, которых никто не ищет.

## Решение

Правила, по которым выбирались заголовки:

1. **Одна страница — один запрос из базы** (`queries/baseline-2026-11-05.csv`),
   запрос вписан в таблицу блока 1 ТЗ №3.
2. **H1 — словами запроса + Новороссийск.** Не больше 70 знаков.
3. **Title — та же фраза, оба города, «АНВ Гарант»** через длинное тире. До 70.
4. **Description — выгода, цена, телефон, город.** До 160.
5. **Запросы про проверку уходят со `/yuristy/` на `/proverka-obekta/`.**
   `юристы` оставляем за «юрист по недвижимости» и «юридическое сопровождение»,
   `сделки` — за «сопровождение сделки с недвижимостью». Так две страницы не
   спорят за один запрос.

| URL | Запрос | H1 |
|---|---|---|
| `/` | агентство недвижимости новороссийск | Недвижимость без скрытых рисков (не меняем) |
| `/proverka-obekta/` | проверка юридической чистоты квартиры новороссийск | Проверка юридической чистоты квартиры перед покупкой в Новороссийске |
| `/yuristy/` | юрист по недвижимости новороссийск | Юрист по недвижимости в Новороссийске и Геленджике |
| `/sdelki/` | сопровождение сделки с недвижимостью новороссийск | Сопровождение сделки с недвижимостью в Новороссийске и Геленджике |
| `/analiz-kommercii/` | анализ коммерческой недвижимости новороссийск | Анализ коммерческой недвижимости перед покупкой в Новороссийске |
| `/prodazha-kommercii/` | продажа коммерческой недвижимости новороссийск | Продажа коммерческой недвижимости в Новороссийске и Геленджике |
| `/zapusk-agentstva/` | запуск агентства недвижимости с нуля | Запуск агентства недвижимости с нуля и под ключ |

Полные title, description и длины — в блоке 1 ТЗ №3, это единственный источник.

## Альтернативы

- **Оставить таблицу блока 1 и не трогать приложения.** Два набора заголовков в
  одном файле: разработчик выбирает наугад, приёмка этого не ловит.
- **Взять набор из приложений.** H1 «Юридическое сопровождение сделок…»
  конкурирует с `/sdelki/` («Сопровождение сделки…») — та самая каннибализация,
  которую ТЗ лечит на других страницах.
- **Оставить H1 «Проверка объекта…» у новой страницы.** Красивее, но это наша
  формулировка, а не запрос; страница вышла бы под фразу без спроса.

## Последствия

- `/yuristy/` теряет формулировку «сопровождение сделки» в H1 и получает блок
  «Когда проверки мало» со ссылкой на `/proverka-obekta/` — дубль H2
  «Что проверяют у объекта перед покупкой» убран с обеих страниц.
- URL `/proverka-obekta/` не меняется, хотя H1 теперь про юридическую чистоту:
  адрес уже в статьях и в ссылках, менять его дороже, чем жить с расхождением.
- Description переписан на всех семи страницах, а не только на
  `/analiz-kommercii/` — прежнее правило «правим только один» противоречило
  приложениям.
- Анкоры в трёх статьях («проверка объекта перед покупкой») остаются как есть:
  анкор не обязан совпадать с H1.
- Длины сверены скриптом: title ≤70, H1 ≤70, description ≤160, значения в
  таблице и в приложениях совпадают дословно.
