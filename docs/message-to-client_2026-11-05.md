# Сообщение заказчику: офисы и карточка

Отправлено 5 ноября 2026 в мессенджер. Ждём ответа; пункты 1–3 блокируют
локальное SEO.

```
Добрый день! Готовлю правки по сайту и карточке в Яндекс Картах.
Чтобы всё совпадало и люди не ехали по старому адресу, нужны
короткие ответы — можно просто номерами.

1. У вас два офиса. Напишите оба адреса полностью: город, улица, дом,
   офис/этаж.

2. В какой из них клиенты приходят на приём, а какой используется
   для документов / юридический адрес?

3. В Геленджике есть офис, куда можно прийти, или вы там работаете
   только выездами и удалённо?

4. Телефон для звонков с сайта и с Карт — один общий или у каждого
   офиса свой? Какой номер основной?

5. В Яндекс Картах у вас висит старый адрес (Дзержинского, 156А) и
   старый сайт (clients.site), а на сайте — Исаева, 2Б. Кто имеет
   доступ к карточке в Яндекс Бизнесе? Нужно либо ваше действие
   (5 минут по инструкции), либо доступ нам.

6. Консультация сейчас платная (от 5 000 ₽) или бывает бесплатная?
   В карточке до сих пор написано «Бесплатная консультация» — надо
   привести к правде.

7. Фото офиса и сотрудников есть свежие? Для карточки и сайта.
```
