# INDEX

Карта документов. Строка → файл, только если совпало «когда».
Полный обход: ~39 600 токенов. Эта карта: ~1 500.

## Правила

- Начни здесь, а не с `README.md`.
- `AGENTS.md` читай один раз целиком: там правила и факты о клиенте.
- `README.md` целиком не читай — бери нужный раздел: `grep -n '^#' README.md`.
- Даты в именах файлов — `YYYY-MM-DD`. Свежее — ниже по таблице, но прав тот,
  кто новее: дата в имени файла важнее позиции строки.
- Код ищи `grep`/`glob` по делу, а не листанием дерева.
