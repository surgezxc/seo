лежат в `16x9/`.

## Почему кабинет один

В видео один кабинет. Резать его на три кадра — дубли, поэтому оставлен один
общий вид. Больше разных фото из этого видео не выжать.

Если нужно 5–6 фото, снимать так: фасад с угла, где не попадают чужие вывески;
входная дверь с улицы; кабинет от двери; стол крупно; окно; логотип на стене.
Днём, без людей, телефоном горизонтально.
